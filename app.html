1. 측정 데이터 가져오기

여기에 엑셀 파일(.xlsx)을 끌어다 놓으세요
또는 클릭해서 파일 선택 · .xlsx / .xlsm / .csv 지원 (구형 .xls는 엑셀에서 .xlsx로 다시 저장 후 사용)

아래에서 검사 정보를 넣고 로트별 검사 수량만 입력하면, 엑셀처럼 칸이 나뉜 입력표가 자동으로 만들어집니다.

엑셀에서 측정값 영역을 마우스로 드래그 → Ctrl+C → 아래 칸 클릭 → Ctrl+V. 제목(규격)과 번호 머리행까지 같이 복사하면 규격·범위를 자동으로 잡습니다.
숫자만 직접 칠 때는 띄어쓰기, 쉼표, 줄바꿈 어느 것으로 구분해도 됩니다.

3. 검사 수량 설정 수량을 넣으면 아래 입력표가 바로 만들어집니다

구분로트 명칭검사 수량
(개)		한 줄 칸 수만들어질 표조건 메모
예) 검사 수량 1,989개 · 한 줄 10칸 → 199줄 표가 자동으로 만들어지고, 마지막 줄의 남는 칸은 회색으로 막힙니다. 수량을 바꿔도 이미 입력한 값은 그대로 남습니다.

4. 측정값 입력

Enter 다음 칸 · Shift+Enter 이전 칸 · 방향키 상하좌우 이동 · 엑셀에서 여러 칸을 복사해 아무 칸에 Ctrl+V 하면 그 칸부터 표 모양대로 채워집니다. 입력 중인 내용은 자동으로 임시 저장됩니다.

2. 인식 결과 확인

범위를 고치면 바로 다시 읽습니다. 미리보기에서 파란 칸이 측정값, 빨간 칸은 규격 밖 값, 노란 칸은 제목으로 잡힌 셀입니다.

사용법

데이터 넣기

  • 엑셀 파일: [데이터 입력] 탭에서 파일을 끌어다 놓거나 클릭해서 고릅니다. 제목 셀에 OF051B 중량 체크 (28~34.02g)처럼 규격을 적어두면 품목명·규격·단위를 자동으로 읽습니다.
  • 번호 머리행: 1, 2, 3 … 10처럼 번호가 붙은 행이 있으면 그 아래 칸을 측정값으로 잡고, 맨 왼쪽 순번 열과 옆의 계산 칸(통과 제품 중량 등)은 빼고 읽습니다.
  • 복사·붙여넣기: 엑셀에서 영역을 드래그해 Ctrl+C, 입력 칸에 Ctrl+V. 파일과 똑같이 인식합니다.
  • 자동 인식이 틀리면 데이터 범위(예: B7:K2085)와 읽는 순서를 직접 고치면 됩니다.
  • 같은 날 같은 품목을 여러 번 검사했다면 로트 번호만 다르게 해서 각각 등록하세요.

판정 기준

  • 규격 하한 ≤ 측정값 ≤ 규격 상한이면 합격. 경계값(예: 34.02)은 합격입니다.
  • Cpk: 공정능력지수. 1.33 이상 양호, 1.00~1.33 관리 필요, 1.00 미만 능력 부족. 음수면 평균 자체가 규격 밖에 있다는 뜻입니다.
  • 극단값: 규격 밖이면서 중앙값에서 표준편차 5배 넘게 떨어진 값. 저울 오류나 기록 실수일 가능성이 높아 따로 표시합니다. 합격·불합격 수량에는 그대로 포함됩니다.
  • 중심 맞춤 시 예상 합격률: 지금 산포 그대로 평균만 규격 중앙으로 옮겼을 때 정규분포로 계산한 추정치입니다.

보관

  • 인터넷 연결이 필요 없습니다. 모든 처리는 이 PC 안에서만 이뤄집니다.
  • 검사 데이터는 프로그램(exe) 옆 data\inspection_data.json 파일에 자동 저장되고, 하루 한 번 data\backup 폴더에 날짜별 사본이 남습니다 (최근 60개 보관).
  • 다른 PC로 옮길 때는 exe와 data 폴더를 통째로 복사하면 그대로 이어서 쓸 수 있습니다.
  • 회사 로고와 회사명은 [데이터 관리] 탭에서 바꿉니다.

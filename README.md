# HBS — (주)한부솔루션 사내 프로그램 저장소

프로그램마다 폴더를 나눠 관리합니다. 각 폴더의 README 에 내려받기 링크와 배포 방법이 있습니다.

| 폴더 | 프로그램 | 내려받기 |
|---|---|---|
| [`전수검사분석/`](전수검사분석/) | 전수검사 데이터 분석 프로그램 (윈도우 실행 파일, 대시보드·보고서) | [HBS_Inspection_setup.zip](https://github.com/JJun-2/HBS/raw/main/전수검사분석/release/HBS_Inspection_setup.zip) |
| [`샘플데이터분석/`](샘플데이터분석/) | 샘플 데이터 분석 프로그램 (구 OxyFelt 조건 셋업 보고서, 브라우저용) | 링크로 사용: https://jjun-2.github.io/Sample-Report/ |

새 프로그램을 추가할 때는 프로그램 이름으로 폴더를 만들고 그 안에 `version.json`, 화면 파일, `release/` 를 둡니다.
맨 위의 `version.json` 은 전수검사분석 v1.3.0 이하 버전이 새 폴더를 찾아가도록 남겨 둔 파일입니다.

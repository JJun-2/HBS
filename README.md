## HBS — (주)한부솔루션 사내 프로그램 저장소

프로그램마다 폴더를 나눠 관리합니다. 각 폴더의 README 에 자세한 사용법과 배포 방법이 있습니다.

| 폴더 | 내용 |
|---|---|
| [`전수검사분석/`](전수검사분석/) | 전수검사 데이터 분석 프로그램 — 실행 파일, 화면, 소스, 배포 도구 |
| [`샘플데이터분석/`](샘플데이터분석/) | 샘플 데이터 분석 프로그램 (구 OxyFelt 조건 셋업 보고서) |

새 프로그램을 추가할 때는 프로그램 이름으로 폴더를 만들고, 맨 위 표에 내려받기 링크를 한 줄 추가합니다.
맨 위의 `version.json` 은 전수검사분석 v1.3.0 이하 버전이 새 폴더를 찾아가도록 남겨 둔 파일이니 지우지 마세요.
